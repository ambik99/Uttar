# Uttar (उत्तर) — CBSE Class 10 & 12 AI Exam Practice, Chapter Notes & Diagrams

A zero-build, single-page React + Tailwind CSS web application for CBSE Class 10 and Class 12 students.

## Features
- **CBSE Practice Paper Generator:** Covers 29 Class 10 & 12 subjects with official CBSE question limits, mark distributions, and section blueprints (MCQ, Assertion/Reason, Competency/Case-Based, Short Answer, Long Answer).
- **AI Chapter Notes & SVG Diagrams:** Chapter-wise NCERT syllabus explorer with definitions, formulas, worked examples, marking tips, inline SVG diagrams, and an **Elaborate** deep-dive mode.
- **CBT Exam Interface:** Live timer, section-grouped question palette, mark-for-review flags, and session persistence in `localStorage`.
- **On-Spot Scorecard & Solutions:** Auto-grading for objective items, CBSE marking-scheme self-evaluation for subjective answers, and topic links to NCERT, DIKSHA, and Khan Academy.
- **Peer Score Comparison:** Generate and import `UTTAR-...` challenge codes to compare scores with friends.
- **Universal BYOK AI Support:** Works with **Google Gemini Direct** (`gemini-3.8-flash`, `gemini-3.6-flash`, `gemini-3.5-flash`, `gemini-4-argon`, etc.) and **OpenRouter** (`sk-or-...`), plus an offline fallback bank.

## Deploy on GitHub Pages
1. Upload all files in this archive (`index.html`, `README.md`, `.gitignore`) to your GitHub repository.
2. Go to **Settings → Pages**, select the `main` branch and `/ (root)` folder, and click **Save**.
3. Open your live GitHub Pages URL, click **Set Universal AI Key** in the top bar, and paste your Gemini or OpenRouter API key.
