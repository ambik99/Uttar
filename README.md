# Uttar (उत्तर) — CBSE Class 10 & Class 12 Exam Practice & Solutions

**Uttar** (*उत्तर* — meaning *Answers* in Hindi) is a responsive, student-friendly CBSE exam practice and performance comparison web application built specifically for **Class 10** and **Class 12** students.

## Key Features
- **Complete CBSE Class 10 & Class 12 Subject Coverage**: Includes Mathematics (Standard & Basic), Science, Social Science, Physics, Chemistry, Biology, Computer Science, Informatics Practices, Accountancy, Business Studies, Economics, History, Political Science, Geography, Psychology, Sociology, Physical Education, IT, AI, Sanskrit, **English**, **Hindi (Course A, B & Core)**, and **Bengali**.
- **Official CBSE Question Limits & Section Blueprints**: Dynamically caps question counts to match official CBSE board exam paper limits.
- **All CBSE Question Formats**: MCQ (1M), Assertion/Reason (1M), Competency/Case-Based (4M), Short Answer (3M), Long Answer (5M), plus **Seen & Unseen Passages** for English, Hindi, and Bengali.
- **On-Spot Scorecard & Dedicated Solutions Tab**: Instant objective grading, interactive CBSE Marking Scheme self-evaluation, and direct internet concept links to NCERT, DIKSHA, Khan Academy India, CBSE Academic, and YouTube.
- **Saved Papers & Friend Score Comparison**: Automatically saves solved papers locally and generates `UTTAR-...` challenge codes to compare scores side-by-side with friends.

## How to Run or Host on GitHub Pages
1. Open `index.html` directly in any modern browser.
2. To host live on GitHub Pages: upload `index.html`, `README.md`, and `.gitignore` to your GitHub repository root, then go to **Settings → Pages → Branch: `main` / `/(root)`** and click **Save**.
